udev rules(arch specific check git repo)
--------------------------------------------------
sudo chmod 644 /etc/udev/rules.d/51-android.rules 
sudo chown root /etc/udev/rules
sudo service udev restart



bootloader unlock
===========================================================================
adb reboot bootloader
fastboot flashing unlock   or fastboot oem unlock ### whichever works
fastboot reboot
fastboot unlock-info

flash recovery,kernel,ROM,Gapps
=================================================================================
fastboot flash recovery <twrp.img>
adb sideload <lineage-os.zip> <open_gpapps-nano.zip>

using identifier token
---------------------------------------------------------
fastboot oem get_identifier_token
fastboot flash unlocktoken <Unlock_code.bin>
