=========================================

sudo sysctl mib

sudo sysctl -a --pattern 'net.ipv4.conf.(eth|wlan)0.arp'

Enable fail2ban
==============================
sudo pacman -Syu fail2ban
sudo systemctl enable fail2ban
sudo systemctl start fail2ban


Prevent IP Spoofing
===================
cat <<EOF > /etc/host.conf
order bind,hosts
multi on
EOF

block packets that specify a source route /etc/sysctl.conf
=================================================================
net.ipv4.conf.default.rp_filter=1
net.ipv4.conf.all.rp_filter=1

then check the same using
--------------------------------------------------------
echo 1 > /proc/sys/net/ipv4/conf/eth0/rp_filter
echo 1 > /proc/sys/net/ipv4/conf/eth1/rp_filter

or

sysctl -w net.ipv4.conf.eth0.rp_filter=1
sysctl -w net.ipv4.conf.eth1.rp_filter=1ps

Limit memory usage from any program (chrome)
=======================================================================
sudo apt-get install cgroup-tools

sudo mkdir -p /sys/fs/cgroup/chrome
echo $((500 * 1024 * 1024)) | sudo tee /sys/fs/cgroup/chrome/memory.max

systemd-run --user --scope -p MemoryMax=512M \
env DISPLAY=$DISPLAY XAUTHORITY=$XAUTHORITY \
/usr/bin/google-chrome-stable

adding repo
-----------------------------------------
replace the URLs(gpg key,stable channel) & name(google-chrome) with proper name

curl -fSsL https://dl.google.com/linux/linux_signing_key.pub | sudo gpg --no-default-keyring --keyring gnupg-ring:/etc/apt/trusted.gpg.d/google-chrome.gpg --import
sudo chmod 644 /etc/apt/trusted.gpg.d/google-chrome.gpg
echo deb [arch=amd64 signed-by=/etc/apt/trusted.gpg.d/google-chrome.gpg] http://dl.google.com/linux/chrome/deb/ stable main | sudo tee /etc/apt/sources.list.d/google-chrome.list
